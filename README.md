## 📌 პროექტის მიმოხილვა
**OTE By AVMA** არის თანამედროვე, სრულფასოვანი ტექსტური და კოდის რედაქტორი, შექმნილი React, TypeScript და Tailwind CSS ტექნოლოგიებით. აპლიკაცია აერთიანებს დოკუმენტების მდიდარ რედაქტირებას (Rich Text Editor), პროგრამირების კოდის რედაქტორს (სინტაქსის ხაზგასმით, ხაზების ნუმერაციით, მოდალური ძიებითა და Undo/Redo მხარდაჭერით), მათემატიკური ფორმულების (KaTeX) ჩასმას, ცხრილებს, ლოკალურ და Cloud საცავს, ასევე Gemini AI ინტელექტუალურ ასისტენტს.

## 🚀 ძირითადი ფუნქციები
- **დოკუმენტის რედაქტორი:** მდიდარი ტექსტის ფორმატირება, სტილები, ფერების პალიტრა, მათემატიკური ფორმულები, ჩექლისტები, სურათები და ცხრილები.
- **ტექსტის ანიმირება & პრეზენტატორი (ტელესუფლიორი):** დოკუმენტის სრული ან შერჩეული ტექსტის ანიმირება პრეზენტაციებისთვის, ტელესუფლიორისთვის, პროექტორზე საჩვენებლად და სუბტიტრებისთვის. მოიცავს 5 უნიკალურ რეჟიმს:
  1. *უწყვეტი გლუვი სქროლვა* (ტექსტი ამოდის სუფთა ეკრანზე სულ ქვემოდან, იწყება ძალიან ნელი ტემპით 0.1x-დან, კლავიატურის ↑/↓ ისრებით მყისიერი აჩქარებითა და შენელებით);
  2. *წინადადებებად შემოსვლა* (წერტილიდან წერტილამდე მკაცრი დაყოფა, სუფთა მკაფიო ტიპოგრაფია ჩრდილების გარეშე, კლავიატურის ისრებით ნავიგაცია, წინადადებების მრიცხველის ჩართვა/გამორთვის ოფციით);
  3. *მორბენალი სტრიქონი (Marquee / Ticker)* (ტექსტი შემოდის ეკრანის მარჯვენა კიდიდან და მოძრაობს მარცხნივ, პიქსელური სიჩქარის რეგულირებით, Space პაუზით და ტექსტის ზომის შეცვლით);
  4. *სტროფებად / აბზაცებად* (პრეზენტაციის სლაიდები Cross-fade, Curtain და Dimming ფოკუსირებით, აქტიური სტროფის ავტომატური ჩასქროლვით);
  5. *სიტყვების თანმიმდევრული გადიდება* (კარაოკე/RSVP, WPM სიჩქარის, მასშტაბისა და აქცენტის ფერის რეგულირებით, აქტიური სიტყვის ავტო-სქროლვით).
  - **წინადადებების შერჩევის ხელსაწყო (Sentence Selector Tool):** შესაძლებლობა ხელით მონიშნოთ მხოლოდ სასურველი წინადადებები (წერტილიდან წერტილამდე, ჩექბოქსებითა და მრიცხველით), გაუშვათ მთლიანი დოკუმენტი ან რედაქტორში უკვე მონიშნული ტექსტი.
  - **ფონის ფერის არჩევანი (ავტომატური კონტრასტული ტექსტით):** მხოლოდ ერთი ფონის არჩევა (მუქი, შავი OLED, ლურჯი, გრაფიტი, თეთრი), სადაც ტექსტის ფერი ავტომატურად იღებს ოპტიმალურ კონტრასტს მაქსიმალური წაკითხვადობისთვის.
  - სრულ ეკრანზე პირდაპირ გაშვება, სარკისებრი რეჟიმი (Mirror Mode მინის სუფლიორებისთვის), Screen Wake Lock (ეკრანის ჩაქრობის პრევენცია), Live Reactive HUD და სწრაფი მორგების პანელი (სიჩქარისა და ზომის ცვლილებები მყისიერად აისახება გაშვებულ პრეზენტაციაზე).
  - გაშვება ხელმისაწვდომია ზედა მენიუს „ხელსაწყოებიდან“ (ინსტრუმენტები), ხელსაწყოთა ზოლიდან და ქვედა მარჯვენა კუთხეში მასშტაბირების ღილაკების გვერდით.
- **კოდის რედაქტორი:** მრავალენოვანი სინტაქსის მხარდაჭერა, Undo/Redo ფუნქციონალი, ხაზების ნუმერაცია, კოდში ფერების კოდების გამოყენება და მარტივი დახურვა (X ღილაკი).
- **ინტეგრირებული AI კოდის ასისტენტი:** კოდის გადაკითხვა და მიმოხილვა, შეცდომების ავტომატური აღმოჩენა და ერთი დაწკაპუნებით გასწორებული კოდის გამოყენება (Apply Fix), იდეებისა და გაუმჯობესებების გენერაცია (Gemini 3.8 Flash, უფასო 15 RPM ტარიფზე ოპტიმიზირებული).
- **AI ასისტენტი (Gemini):** ინტელექტუალური ჩათი, ტექსტის გაუმჯობესება და ანალიზი.
- **ლოკალური დაცვა (Local-First):** მონაცემები ინახება ბრაუზერის IndexedDB/LocalStorage-ში, ინტერნეტის გარეშეც მუშაობის სრული გარანტიით.
- **PWA მხარდაჭერა:** აპლიკაცია სრულად მზადაა ოფლაინ გამოყენებისა და დესკტოპ/მობილურ მოწყობილობებზე ინსტალაციისთვის.
- **მრავალენოვანი ინტერფეისი:** სრული ლოკალიზაცია ქართულ, ინგლისურ და ესპანურ ენებზე.

## 🛠️ პროექტის არქიტექტურა და სტრუქტურა
```text
├── components/          # UI კომპონენტები (Editor, Toolbar, CodeEditorView, MenuBar, Modals...)
│   └── icons/          # ცენტრალიზებული SVG ხატულები
├── lib/                 # დამხმარე ბიბლიოთეკები (googleDrive, translations, templates, db)
├── store/               # მდგომარეობის მართვა (uiStore - Zustand)
├── types/               # TypeScript ტიპები და ინტერფეისები
├── App.tsx              # მთავარი აპლიკაციის კონტეინერი
├── index.html           # HTML5 სტრუქტურა და გარე ბიბლიოთეკები
├── vite.config.ts       # Vite-ის კონფიგურაცია და გარემოს ცვლადების მხარდაჭერა
└── service-worker.js    # ოფლაინ PWA სერვის-ვორკერი
```

## ⚙️ ლოკალური გაშვება

### წინაპირობა:
- [Node.js](https://nodejs.org/) (ვერსია 18+)

### ნაბიჯები:
1. დააინსტალირეთ დამოკიდებულებები:
   ```bash
   npm install
   ```

2. შექმენით `.env.local` ფაილი პროექტის მთავარ დირექტორიაში:
   ```env
   GEMINI_API_KEY=თქვენი_gemini_api_გასაღები
   ```

3. გაუშვით დეველოპმენტ სერვერი:
   ```bash
   npm run dev
   ```

## 🌐 Vercel-ზე დეპლოიმენტის ინსტრუქცია

1. ატვირთეთ პროექტი თქვენს GitHub რეპოზიტორიაში.
2. შედით [Vercel](https://vercel.com)-ზე და დააიმპორტეთ რეპოზიტორია `texteditor.01`.
3. **Environment Variables** სექციაში დაამატეთ:
   - **Key:** `GEMINI_API_KEY` (ან `VITE_GEMINI_API_KEY`)
   - **Value:** თქვენი Google Gemini API გასაღები (Google AI Studio-დან, უფასო 15 მოთხოვნა/წუთში ტარიფით).
4. დააჭირეთ **Deploy** ღილაკს. სისტემა ავტომატურად ააწყობს და გაუშვებს აპლიკაციას უმაღლესი წარმადობით.
